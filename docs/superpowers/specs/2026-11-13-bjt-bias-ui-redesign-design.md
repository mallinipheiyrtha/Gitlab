# BJT Bias Web App — UI Redesign (Lab 02 look) — Design

วันที่: 2026-11-13
สถานะ: อนุมัติโดยเจ้าของโปรเจกต์แล้ว

## ทำไม (intent)

หน้าเว็บปัจจุบันเป็นคอลัมน์เดียว ธีมแดง-ครีม และไม่แสดง error ของฟอร์มเลย
เจ้าของโปรเจกต์ต้องการให้หน้าตาเหมือนภาพ mockup ของแล็บ (หัวเรื่อง Lab 02,
การ์ด 3 คอลัมน์, แถบสรุปย่านการทำงาน, แถบ Week 2 Goal) โดย **ไม่เปลี่ยนตัวเลข
หรือสูตรคำนวณใด ๆ**

## เป้าหมาย

- หน้าตาเป็นไปตาม mockup: header พร้อมไอคอนชิป + กรอบ "Computer Programming
  for Electrical Engineers", เนื้อหา 3 คอลัมน์ (Input / Circuit / Results),
  แถบสถานะย่านการทำงาน, แถบ Week 2 Goal ท้ายหน้า
- คงพฤติกรรมเดิมทุกอย่าง: ฟิลด์อินพุต 7 ตัว, หน่วย V/Ω โดยตรง, ผลลัพธ์
  VBB/RB/IB/IC/IE/VCE, การตรวจสอบข้าม Thevenin vs bisection, แสดงผลเฉพาะ
  หลัง POST
- แก้บั๊กที่มีอยู่: แสดง validation error รายช่อง, มี `id="results"`,
  ป้ายย่านเป็นภาษาไทย "แอกทีฟ" ให้ smoke test ผ่าน

## ไม่ทำ (non-goals)

- ไม่เพิ่ม VB/VE/VC หรือหน่วย µA (ไม่ได้อยู่ในสูตรเดิม)
- ไม่ทำ dropdown แปลงหน่วย kΩ หรือแปลงค่าอินพุตใด ๆ
- ไม่แตะ `bjt.py` (สูตร/การตรวจสอบ/การแบ่งย่านคงเดิม)
- ไม่ใช้ JavaScript, ไม่ใช้ CDN/framework ภายนอก

## ข้อจำกัด

- ต้องรักษาสัญญาของ route และฟิลด์ฟอร์มเดิม (`vcc`, `r1`, `r2`, `rc`, `re`,
  `beta`, `vbe`) เพราะ `test_flask.py` และ `bjt_bias/tests` อ้างอิงอยู่
- smoke test ที่รากต้องการ: `name="..."` ครบ, มี "Ω", มี `id="results"`,
  ข้อความ "1.286", "4.655", "แอกทีฟ", "ตรงกัน" และข้อความ error
  "ต้องมากกว่า 0"
- หน้าเดียว ไม่มี asset ภายนอก (ทำงานได้แบบออฟไลน์ในห้องแล็บ)

## ทางเลือกที่พิจารณา

| ทางเลือก | ข้อดี | ข้อเสีย | สรุป |
|---|---|---|---|
| A. เขียนใหม่เฉพาะ `templates/index.html` (CSS + SVG ฝังในไฟล์) | ไฟล์เดียว ไม่เพิ่ม dependency รักษา route เดิม | ไฟล์ HTML ยาวขึ้น | **เลือก** |
| B. แยก `static/style.css` + partial | โครงสร้างโตง่าย | เพิ่มไฟล์/โครงสร้างโดยไม่จำเป็นกับหน้าเดียว | ไม่เลือก |
| C. Bootstrap/Tailwind ผ่าน CDN | ทำเร็ว | ต้องพึ่งอินเทอร์เน็ต ไม่ตรงเจตนาให้เบา/ออฟไลน์ | ไม่เลือก |

## ดีไซน์ที่ตกลง

1. **โครงหน้า:** `.app` กว้างสูงสุด ~1500px, header เต็มกว้าง, main เป็น
   `grid-template-columns: 1fr 1.15fr 1fr` (จอ < 1100px ยุบเป็นคอลัมน์เดียว,
   < 640px ปรับระยะห่าง)
2. **Header:** ไอคอนชิปแบบ inline SVG, h1 "Lab 02: BJT DC Bias Web App",
   บรรทัดรอง "ENG29 2121 – Common Emitter (Voltage Divider Bias)",
   กรอบสีฟ้าอ่อนด้านขวาพร้อมไอคอน `</>` และข้อความ "Computer Programming for
   Electrical Engineers"
3. **การ์ดอินพุต:** ไอคอนเฟือง + หัวข้อ "Input Parameters" (อังกฤษตามภาพ)
   แต่ละแถว: label ทางซ้าย (เช่น `V_CC (Supply Voltage)`), input กลาง,
   หน่วย V/Ω/– เป็นกล่องข้อความนิ่งทางขวา; ใต้ input แสดง error สีแดงเมื่อมี
   (`errors[field]`) และคง `values` ที่ผู้ใช้กรอก; ปุ่ม submit เต็มความกว้าง
   สี teal "คำนวณ DC Bias" พร้อมไอคอนเครื่องคิดเลข
4. **การ์ดวงจร:** inline SVG แผนภาพ voltage-divider bias (R1, R2, RC, RE,
   Q1 NPN, VCC, GND) พร้อมป้ายค่าที่ format จากค่าฟอร์มปัจจุบัน (เช่น 47000 →
   47 kΩ) — เป็นการแสดงผลเท่านั้น ไม่ใช่การคำนวณใหม่; ใช้ค่าตั้งต้นเมื่อยัง
   ไม่ได้ส่งฟอร์ม
5. **การ์ดผลลัพธ์:** `id="results"`; ตาราง 6 แถว (VBB, RB, IB, IC, IE, VCE)
   สลับสีพื้นหลัง; ป้ายย่าน "แอกทีฟ (Active)" / "แซทเทอเรชัน (Saturation)" /
   "คัตออฟ (Cutoff)" พร้อมสีเขียว/ส้ม/แดง; แสดง `warning` ของเดิมถ้ามี;
   กล่อง "การตรวจสอบข้าม" คงข้อความเดิม (Thevenin, เชิงตัวเลข, ผลตรงกัน/
   ไม่ตรงกัน, delta) แต่จัดสไตล์เป็นการ์ดสรุปสีเขียว (ตรงกัน) หรือส้ม
   (ไม่ตรงกัน)
6. **แถบ Week 2 Goal:** การ์ดสีฟ้าอ่อนท้ายหน้า แสดงเป้าหมายแล็บตาม README
   (สร้างเว็บ Flask รับพารามิเตอร์วงจรและคำนวณไบแอส DC ของ common-emitter
   แบบแบ่งแรงดัน)
7. **ภาษาผสม:** หัวข้อการ์ด/ป้าย单位为อังกฤษตามภาพ; คำอธิบายช่อง, error,
   warning, กล่องตรวจสอบเป็นไทยเหมือนเดิม
8. **การเข้าถึง:** ผูก `label for` กับ input ทุกตัว, มี focus ring ชัด, ไม่มี
   การพึ่งสีเพียงอย่างเดียว (มีข้อความกำกับย่าน)

## สิ่งที่ปล่อยให้ผู้ลงมือตัดสิน

- ค่าความกว้าง/ระยะห่าง/เฉดสีที่ใกล้เคียงภาพที่สุดโดยไม่ต้องมีไฟล์ดีไซน์
- วิธี format ค่าในวงจร (kΩ/MΩ) และการปัดเศษ (ต้องตรงกับค่าที่กรอก)
- การจัดวาง SVG ให้อ่านง่ายทั้งจอกว้างและจอแคบ
