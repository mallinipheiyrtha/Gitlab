# BJT Results: VB/VE/VC + SI units — Design

วันที่: 2026-11-13
สถานะ: เจ้าของโปรเจกต์กำหนดสมการและอนุมัติแนวทางแล้ว

## ทำไม

ตาราง DC Bias Results ต้องแสดงแรงดันที่โหนดจริงของวงจร (VB, VE, VC) ไม่ใช่แค่ปริมาณ
Thevenin (VBB, RB) และต้องแสดงกระแส/แรงดันด้วยหน่วย SI ที่เหมาะกับขนาดค่า
(เช่น 12.863 µA แทน 0.013 mA) เพื่อให้อ่านผลแล็บได้ตรงกับที่วัดจริง

## สมการอ้างอิง (จากเจ้าของโปรเจกต์ — ต้องตรงตามนี้)

- VTH = VCC × R2 / (R1 + R2)
- RTH = R1·R2 / (R1 + R2)
- IB = (VTH − VBE) / (RTH + (β + 1)·RE)
- IC = β·IB, IE = (β + 1)·IB
- VE = IE·RE
- VB = VE + VBE
- VC = VCC − IC·RC
- VCE = VC − VE

## ขอบเขต

- เพิ่มฟิลด์ `vb_v`, `ve_v`, `vc_v` ใน `BiasResult` ของ `bjt_bias/bjt.py`
  โดยคำนวณจากสมการข้างบนในทุกเส้นทาง (active / saturation / cutoff)
- ตารางผลลัพธ์แสดง 7 แถว: VB, VE, VC, VCE, IB, IC, IE
- ตัวกรอง `si` ใน `bjt_bias/app.py` เลือก prefix วิศวกรรม (p, n, µ, m, หน่วยฐาน, k, M, G)
  ให้ mantissa อยู่ในช่วง 1–999 แล้วแสดงทศนิยม 3 ตำแหน่ง (ตัดศูนย์ท้าย)
- VBB/RB ย้ายไปเป็นบรรทัดสรุปเล็ก ๆ ใต้ตาราง (คงค่าไว้ให้ตรวจสอบย้อนกลับ)
- กล่อง "การตรวจสอบข้าม" ใช้หน่วย SI เช่นกัน

## กรณีย่านผิดปกติ

- **Cutoff (IB ≤ 0):** ไม่มีกระแส → VE = 0, VC = VCC, VB = VTH (ฐานถูกกำหนดโดยตัวแบ่งแรงดัน
  ไม่ใช่ VBE = 0.7) และ VCE = VCC
- **Saturation:** รายงานค่าจากสมการแอกทีฟตามเดิมพร้อมคำเตือน (VE/VB/VC คำนวณจากสูตรเดียวกัน)

## ไม่ทำ

- ไม่เปลี่ยนสูตร Thevenin/bisection หรือเกณฑ์แบ่งย่าน
- ไม่เปลี่ยนหน่วยอินพุต (ยังเป็น V/Ω ตรงตัว)
- ไม่แตะ VBB/RB ในเชิงค่า คงไว้เป็นข้อมูลตรวจสอบ
