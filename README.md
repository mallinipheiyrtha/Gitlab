DC Circuit Calculator (โปรแกรมคำนวณและวิเคราะห์วงจรตัวต้านทาน)
คำอธิบายโครงงาน
โปรแกรมคำนวณและวิเคราะห์วงจรไฟฟ้ากระแสตรง (DC) สำหรับวงจรตัวต้านทานที่ต่อแบบอนุกรม ขนาน และผสม โดยผู้ใช้สามารถระบุค่าแรงดันไฟฟ้าและค่าความต้านทาน เพื่อคำนวณหาค่ากระแสไฟฟ้ารวม กระแสไฟฟ้าย่อย และกำลังไฟฟ้าในแต่ละจุดได้อย่างแม่นยำและรวดเร็ว
